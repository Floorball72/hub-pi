# swiss unihockey: Ablauf pro Einsatz

Diese Datei füllt Jerome mit dem Ablauf von Marion Kaufmann (Verantwortliche Kommunikation).
Der Hub liest daraus die Standard Checkliste für jeden Einsatz. Bis hier Schritte stehen, ist die
Checkliste leer und kann in der Oberfläche frei befüllt werden.

Format: Jede Zeile, die mit `- [ ]` beginnt, wird ein Schritt. Überschriften (`## ...`) gliedern die
Schritte in Abschnitte. Alles andere wird ignoriert. Für einen Typ (Resultatpost oder Matchbericht)
gilt ein Abschnitt nur, wenn die Überschrift den Typ enthält, zum Beispiel `## Matchbericht`.
Abschnitte ohne Typ im Namen gelten für alle Einsätze.

Keine Zugangsdaten in diese Datei schreiben. Der geteilte Login gehört nur in die `.env`.
